The public website above is already published. You may also host your downloaded copy on GitHub Pages. GitHub confirms that Pages is available for public repositories with GitHub Free:

https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, then **main** and **/(root)**.
